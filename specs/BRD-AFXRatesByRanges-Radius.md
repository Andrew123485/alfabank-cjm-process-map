## Обзор задачи

Нужно перенести экран просмотра котировок AlfaFX (виджет **AFXRatesByRanges**) из IB-Dealing в Radius. Экран показывает индикативные котировки по диапазонам объёмов.

**Что такое индикативные котировки.** Индикативная цена — это цена без обязательства дилера покупать и продавать трейдеру рыночные продукты по этой цене. Функционал предоставления цен по списку инструментов традиционно называется «индикативными котировками», хотя это не совсем корректно: в проекте котирования розницы по этим ценам предполагается совершать реальные конвертации.

**В каком разрезе показываются котировки:**
- **Спред-группа** — набор настроек котирования (спреды по диапазонам объёмов) для конкретного тех. логина. Экран показывает котировки, рассчитанные по выбранной спред-группе.
- **Канал котирования** — тех. логин системы-потребителя. Разные каналы могут иметь разные настройки котирования.
- **PIN клиента (опционально)** — клиент с индивидуальной спред-группой. Если выбран PIN, показываются котировки по его индивидуальной спред-группе.

Экран **не создаёт сделки и не редактирует настройки** — это экран просмотра. Данные приходят из сервиса `WSAlfaForexRatesByRanges12#Get` (через IB Core), часть полей вычисляется на стороне UI.

Источник: https://confluence.moscow.alfaintra.net/spaces/URSIB/pages/1459694139/ (разделы 1.1, 3.1, 4.1, 4.9.1); https://confluence.moscow.alfaintra.net/spaces/URSIB/pages/416185946/ (определение индикативных котировок)

## Допущения, предположения и исключения

**Допущения:**
- Сервис `WSAlfaForexRatesByRanges12#Get` остаётся доступным и не меняет контракт в рамках задачи.
- Расчёт котировок остаётся в IB Core — в Radius переносится только UI.
- Список каналов формируется из `SystemClient`, где `server_system_ref = AlfaFX`.
- Значения по умолчанию указаны для профиля `default`. Если используется другой профиль, значения по умолчанию подтягиваются из профиля.

**Исключения (вне скоупа):**
- Логика расчёта спредов и котировок (остаётся в IB Core).
- Настройка/редактирование спред-групп (это отдельный интерфейс `AFXDicGroupSpreadParamQuot`).
- Создание сделок и конвертаций.
- **[УТОЧНИТЬ]** — нужен ли перенос других виджетов (`RawRates`, `AFXDealRateErrors`, `TestRatesOnMarket`).

## Схема бизнес-процессов TO BE

В Radius создаётся процесс просмотра котировок, которого ранее не было.

**Описание процесса:**

1. Пользователь (sales/trader деска FX) открывает в Radius экран **«Просмотр котировок»**.
2. Radius автоматически вызывает сервисы-справочники и заполняет выпадающие списки:
   - **Группа по спреду** — из `IBCR_UWSAlfaForexSpreadGroupBasicParam10#Get` (по умолчанию `NIB`).
   - **Канал** — из `IBCR_UWSAlfaForexSystemClient10#Get` (где `server_system_ref = AlfaFX`, по умолчанию `NIB`).
   - **PIN** — из `IBCR_UWSAlfaForexPINBySpreadGroup10#Get` (по умолчанию пусто).
   - **Инструменты** — из `IBCR_UWSAlfaForexCurrencyPair11#Get`.
3. Пользователь задаёт **Период, сек** (по умолчанию 1 сек) и при необходимости выбирает спред-группу / канал / PIN.
4. Radius **каждые N секунд** вызывает `WSAlfaForexRatesByRanges12#Get` с параметрами:
   - `Spread-group-id` — id выбранной спред-группы;
   - `login` — выбранный канал (`client_system_ref`);
   - `Instruments` — список `currency_pair_ref`;
   - `Source` = `true`.
5. Radius заполняет **табличную часть 1** (по инструментам) и **табличную часть 2** (по диапазонам объёмов).
6. Пользователь нажимает **Apply** — применяются новые параметры (спред-группа, канал) и период вызова.
7. Пользователь нажимает **Reset Panel** — параметры сбрасываются к значениям по умолчанию.

**Логика связей полей:**
- Выбор **PIN** → в поле «Группа по спреду» подставляется `spread_group_id` этого PIN.
- Изменение **«Группы по спреду»** → поле **PIN** очищается.

**Обработка ошибок:**
- Если сервис-справочник вернул ошибку — всплывающее окно с текстом ошибки; при `errorCode = -101` — «Учетная запись IB Dealing недоступна».
- Если `WSAlfaForexRatesByRanges12#Get` вернул ошибку — табличные части не заполняются, показывается всплывающее окно с ошибкой.

**Риски и их митигация:**

| Риск | Митигация |
| --- | --- |
| Сервис `WSAlfaForexRatesByRanges12#Get` недоступен | Показать ошибку пользователю, не заполнять таблицы; **[УТОЧНИТЬ]** — нужен ли ретрай |
| Большой список PIN (до 36 000) тормозит загрузку | **[УТОЧНИТЬ]** — в источнике отмечена проблема «ддосить baseinfo по списку»; нужен ли поиск по PIN |
| Расхождение визуализации с IB-Dealing | Сверить макеты и правила отрисовки (раздел 4.9 FSD) |

**BPMN-схема TO BE** — см. Приложение 6 и файл `to be RatesByRanges.drawio`.

## Варианты использования конечными пользователями

**[УТОЧНИТЬ]** — опционально для небольшого BRD. Возможные сценарии:

1. **Просмотр котировок по спред-группе** — sales выбирает спред-группу и канал, смотрит таблицы.
2. **Просмотр котировок по PIN клиента** — sales выбирает PIN, система подставляет спред-группу, показывает индивидуальные котировки.
3. **Смена канала котирования** — trader переключает канал, сравнивает котировки.
4. **Сброс параметров** — пользователь нажимает `Reset Panel`.

## Приложение 1. Правила отрисовки (раздел 4.9.1 FSD)

### Табличная часть 1

Для каждой структуры `Instrument` из ответа `WSAlfaForexRatesByRanges12#Get` формируется отдельная строка:

| Колонка | Источник |
| --- | --- |
| CCY | часть параметра `instrument` **до** знака `/` |
| XCCY | часть параметра `instrument` **после** знака `/` |
| Rate | вычисляемое поле, `(BID + ASK) / 2` |
| BID | параметр `priceBid` для **минимального** `ccyVolumeFrom` из структуры `price` |
| ASK | параметр `priceOffer` для **минимального** `ccyVolumeFrom` из структуры `price` |
| Spread | вычисляемое поле, `ASK − BID` |
| AutoQuoteLimit | параметр `autoQuoteLimit` |
| ErrorCode | параметр `ErrorCode`. Если `ErrorCode = 0` — строка синяя, иначе — красная |
| ErrorText | параметр `errorDesc` |
| Source | параметр `source` |

### Табличная часть 2

Для каждой структуры `price` формируется отдельная строка. Структуры `price` сортируются по возрастанию `ccyVolumeFrom`:

| Колонка | Источник |
| --- | --- |
| VolumeFrom | параметр `ccyVolumeFrom` |
| VolumeTo | параметр `ccyVolumeFrom − 0,01` |
| Rate | вычисляемое поле, `(BID + ASK) / 2` |
| BID | параметр `priceBid` |
| ASK | параметр `priceOffer` |
| Spread | вычисляемое поле, `ASK − BID` |

## Приложение 5. Параметры вызова сервиса WSAlfaForexRatesByRanges12#Get (раздел 4.8 FSD)

| Параметр | Правило заполнения | Обязательность |
| --- | --- | --- |
| X-External-System-Code | Заполняется на основании настроечных файлов | Обязательное |
| X-External-User-Code | Заполняется на основании настроечных файлов | Обязательное |
| Spread-group-id | id спред-группы, выбранной в интерфейсе в поле «Группа по спреду» | Обязательное |
| login | канал, выбранный в интерфейсе в поле «Канал» (`client_system_ref`) | Обязательное |
| Instruments | Список `currency_pair_ref` из ответа сервиса `IBCR_UWSAlfaForexCurrencyPair11#Get` | Не обязательное |
| Source | `true` | Не обязательное |

**Структура ответа:**

| Поле | Описание |
| --- | --- |
| spreadGroupId | Код спред-группы |
| spreadGroupName | Наименование спред-группы |
| instruments | Список структур Instruments |
| source | Источник котировки |

**Структура Instruments:**

| Поле | Описание |
| --- | --- |
| errorCode | Код ошибки |
| errorDesc | Описание ошибки |
| instrument | Валютная пара |
| prices | Список структур prices |

**Структура prices:**

| Поле | Описание |
| --- | --- |
| ccyVolumeFrom | Начальное значение диапазона объемов в единицах базовой валюты инструмента |
| priceBid | Цена BID индикативной котировки для данного инструмента и диапазона объемов |
| priceOffer | Цена ASK индикативной котировки для данного инструмента и диапазона объемов |
